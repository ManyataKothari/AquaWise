
# AquaWise 3.0

Explore. Simulate. Decide. Conserve.

## About the Project

AquaWise is an interactive water resource management
platform that combines advanced algorithms, climate
simulations and gamification to promote water conservation.

## Features

- National Dashboard: Overview of water availability,
  demand and shortages.
- India Water Atlas: Interactive district-wise water analysis.
- El Niño Experience: Animated climate and drought simulations.
- Water Allocation: Optimized water distribution.
- Solution Planner: Budget-based conservation planning.
- Future Water Plan: 30, 60 and 90-day shortage estimates.
- Pollution Lab: Impact of contamination on water availability.
- Save Your District: Interactive water management game.
- My Water Footprint: Personal water consumption calculator.
- Quality Explorer: District search and report verification.
- Algorithm Visualizer: Step-by-step algorithm demonstrations.

## Save Your District - Game

Players act as water resource managers and tackle
different water crises within a limited budget.

Their selected conservation projects are compared
against the optimal solution generated by the Knapsack
algorithm.

The game encourages strategic thinking, decision-making,
budget management and environmental awareness.

## Algorithms Implemented

| Algorithm | Application |
|---|---|
| Edmonds-Karp | Maximum water flow and distribution |
| 0/1 Knapsack | Budget-based project optimization |
| Trie | Efficient district prefix searching |
| Bloom Filter | Probabilistic report membership checking |

## How to Run

### Backend

```bash
cd backend
mvn spring-boot:run
```

Backend URL: http://localhost:8081

### Frontend

Open a separate terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend URL: http://localhost:5173

## Data Transparency
